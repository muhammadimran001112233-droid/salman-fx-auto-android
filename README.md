Salman FX

Salman FX एक Android trading dashboard है।

Features

- 📊 Trading dashboard
- 📈 Market analysis interface
- 🤖 Automated trading controls
- 💰 Demo trading support
- 📱 Mobile-friendly design
- ⚙️ Trading settings
- 🔔 Trade status display

Android App

यह प्रोजेक्ट Android APK के रूप में build किया जा सकता है।

APK build होने के बाद उपयोगकर्ता Android मोबाइल में ऐप install कर सकता है।

Important

यह ऐप केवल testing/demo purposes के लिए इस्तेमाल करें। वास्तविक पैसे से trading करने से पहले सभी settings और trading logic को अच्छी तरह test करें।
